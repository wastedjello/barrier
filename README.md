
# Raspberry Pi License Plate Detection Barrier System

A Raspberry Pi–based Automatic Number Plate Recognition (ANPR) system using:
- Pi Camera
- OpenCV
- Tesseract OCR
- Arduino-controlled servo barrier

## Features
- Real-time license plate detection
- OCR with strict plate validation
- CSV/Excel logging
- USB serial trigger to Arduino
- Designed for barrier / gate automation

## Hardware
- Raspberry Pi (ARM64)
- Raspberry Pi Camera
- Arduino Uno
- Servo motor

## Software
- Python 3
- OpenCV
- Tesseract OCR
- Picamera2
- Pandas

# How to Run
- Connect required peripherals to Raspberry Pi 5
- SSH to Raspberry Pi
- Activate required VENV with required Python modules
- Navigate to folder
- Run 'mobile_test.py'
